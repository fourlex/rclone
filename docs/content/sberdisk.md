# SberDisk

[SberDisk](https://sberdisk.ru/) is a cloud storage service from Sber.

## Configuration

SberDisk doesn't provide WebDAV or a public OAuth API, so rclone uses the
session cookie from the SberDisk web client.

1. Log in at <https://files.sberdisk.ru>.
2. Open the browser developer tools and select the Network tab.
3. Select any request to `https://apigw.sberdisk.ru`.
4. Copy the full `Cookie` request header.
5. Run `rclone config` and paste it into the `cookie` option.

The cookie is a secret. Treat it like a password and don't share it.

## Limitations

SberDisk doesn't provide settable modification times or file checksums.
rclone therefore treats this backend as having no modification time
support and compares files by size. If a file changes but keeps exactly the
same size, use `--ignore-times` to force the transfer. `--checksum` isn't
available because SberDisk doesn't expose file hashes.

The session cookie expires after a while. If rclone reports
`InvalidAuthorization`, log in again and update the `cookie` option.

Deleting files moves them to the SberDisk trash. Empty the trash in the web
client to reclaim the space.

The API used by this backend is the private API of the SberDisk web client,
so it may change without notice.

### Standard options

Here are the Standard options specific to sberdisk (SberDisk).

#### --sberdisk-cookie

SberDisk session cookie.

Log in at https://files.sberdisk.ru, open the browser developer tools,
find a request to https://apigw.sberdisk.ru, and copy the full Cookie
request header (all cookies, not just _sa).

**NB** Input to this must be obscured - see [rclone obscure](/commands/rclone_obscure/).

Properties:

- Config:      cookie
- Env Var:     RCLONE_SBERDISK_COOKIE
- Type:        string
- Required:    true
